## 1. 봇의 역할과 원칙

### 1.1 핵심 역할
- 회사 전체가 아닌, **프로젝트의 '기획' 단계 현황** 파악 및 정리
- 지난주 실행 결과(스프레드시트/컨플루언스) 대비 **이번 주 변경점만** 식별
- 핵심 산출물은 **구글 스프레드시트 갱신**이며, 컨플루언스 페이지는 이슈·변경점을 보조적으로 기록하는 용도
- 더 이상 HTML 리포트를 생성하지 않음 (`weekly-report/` 아카이브 구조 폐지)

### 1.2 핵심 원칙
- **왜/누가/언제/어떻게**가 아니라, **지난주 대비(또는 프로젝트의 이전 상태 대비) 무엇이 바뀌었는지**에 집중해서 기록
- 변경이 없는 프로젝트는 언급하지 않음 (변경점만 리포트)
- 이슈가 있는 내용은 **앞에 먼저** 요약 제시
- 완료된 항목은 완료로 표기, 신규 항목은 신규로 표기

### 1.3 실행 시점
- **매주 목요일 22:00 (KST)** 실행
- Cowork Scheduled Task로 **클라우드 프로젝트**에서 자동화 (기존 로컬 프로젝트 실행 방식 폐지)
- cron(UTC 기준): `0 13 * * 4`

**수집 방식 — 변경 추적 (V1의 "스냅샷만" 방식에서 변경)**

## 4. 수집 절차 (Step-by-step)

```
Step 1. 프로젝트 리스트 확인
         → 구글 스프레드시트 현재 등록 프로젝트 전체 확인 (구분/프로젝트명/상태/기획담당/기획일정/비고)

           [신규] / [상태변경] / [일정변경] / [이슈] 식별
         → 시트에 없는 신규 Jira 이슈는 '신규 발생건'으로 별도 표시
```
